# Taco Bell Menu Prices and Calories 2026

A structured dataset containing **172 Taco Bell U.S. menu listings across 11 categories**, including reference prices, calorie information, product names, and official menu sources.

## Dataset Information

- **Coverage:** United States
- **Data period:** September 2026
- **Reviewed:** September 12–13, 2026
- **Records:** 172 menu listings
- **Categories:** 11
- **Format:** CSV
- **Columns:** 9
- **License:** CC BY 4.0

## Original Research and Data Source

This dataset was independently compiled by TacoBellMenu.org using publicly available Taco Bell U.S. menu and nutrition information.

**[View the original Taco Bell Price & Calorie Index 2026, research findings, and methodology](https://tacobellmenu.org/price-calorie-index/)**

Official menu reference: https://www.tacobell.com/food

## Dataset Columns

| Column | Description |
|---|---|
| category | Taco Bell menu category |
| item | Menu item name |
| reference_price | Reference price in USD |
| calories_str | Displayed calorie value or range |
| calorie_min | Minimum listed calories |
| calorie_max | Maximum listed calories |
| site_url | Related TacoBellMenu.org product page |
| official_source | Official Taco Bell menu reference |
| reviewed_date | Original review date |

## Methodology

Menu listings were collected and organized using publicly available Taco Bell U.S. menu resources.

Prices are reference values rather than guaranteed local restaurant prices. Calorie ranges are retained for meals with multiple choices or customizations.

Some products appear in multiple categories, meaning the dataset contains 172 listings rather than 172 unique products.

## Research Applications

- Fast-food menu price comparisons
- Nutrition and calorie analysis
- Budget-friendly meal research
- Restaurant pricing studies
- Data visualization and statistical analysis

## Limitations

This dataset represents a September 2026 snapshot, not a live menu feed. Prices, availability, and nutritional information may vary by location, restaurant participation, customization, and date.
